## Precious Ndegwa - VS Code Tools

I use **VS Code** as my main code editor because it is lightweight and powerful.

My top 3 tools and shortcuts are:
- **Emmet**: I type `!` and press `Tab` to generate a full HTML boilerplate instantly. It saves a lot of time.
- **Live Server Extension**: This extension helps me preview my web pages in real-time. Every time I save, the browser refreshes automatically.
- **GitLens Extension**: It shows me who changed which line of code and when. This is very useful for team collaboration to understand the history of a file.

Another useful shortcut I learned is `Ctrl + D` to select multiple occurrences of the same word, and `Ctrl + P` for quick file navigation. I also use *Prettier* for auto-formatting my code to keep it clean.

For more tips, I refer to the official [VS Code Documentation](https://code.visualstudio.com/docs).

## Purity Wanjiku - Git & Terminal Tips

In this project, I focused on Git and Terminal workflows that make collaboration easier and faster.

**1. My Git Workflow & Tips:**

When working on a group project, Git helps me track changes and avoid overwriting someone's work. This is my daily flow:

*   **Before I start:** I always run `git pull origin main` to get the latest code from the team.
*   **While working:** I use `git status` frequently to see which files I have modified. It helps me avoid committing unnecessary files.
*   **Saving work:** I use `git add .` to stage my files, then `git commit -m "clear message"` - I learned to write clear messages like "Added contact form" instead of "fixed stuff".
*   **Pushing & Branching:** I push with `git push origin main`. For new features, I create a branch using `git checkout -b feature-name` so I don't break the main code. I check my branches with `git branch`.
*   **Reviewing:** `git log --oneline` helps me see a short history of all commits, and `git diff` helps me see what exactly changed before committing.

**2. My Terminal Productivity Tips:**

The terminal looked scary at first, but now it saves me a lot of time:

*   **Navigation:** `cd portfolio` to enter a folder, `cd ..` to go back, and `pwd` to confirm where I am.
*   **File Management:** `ls` to list files, `mkdir new-folder` to create a folder, and `touch index.html` to create a file quickly.
*   **Efficiency:** I use `clear` to clean the screen when it gets messy. I use Tab for autocomplete so I don't type long folder names.
*   **VS Code Integration:** I mostly use the integrated terminal in VS Code (Ctrl + `). It means I can code and run git commands in the same window.

Mastering these basic commands has made me more confident in handling projects and working as a team.
